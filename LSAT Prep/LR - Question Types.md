# LR — Question Types

> Know the question type before you read the stimulus. It determines what you're hunting for.
> Back to [[LSAT Prep Hub]]

---

## The Core Question Types

### 1. Flaw
**What it asks:** What is wrong with the argument's reasoning?
**What to do:** Find the gap between premises and conclusion. Name the flaw structurally.
**Common traps:** Picking an answer that describes what the argument *says* rather than what's *wrong* with it.
> See [[LR - Common Flaws]] for a full flaw reference.

---

### 2. Necessary Assumption (NA)
**What it asks:** What must be true for the argument to work?
**What to do:** Find the gap. The NA plugs it — just barely.
**Negation Test:** Negate each answer choice. If negating it *destroys* the argument, it's the NA.
**Key:** NA answers do the minimum. They don't *strengthen* — they just prevent collapse.

---

### 3. Sufficient Assumption (SA)
**What it asks:** Which answer, if true, *guarantees* the conclusion?
**What to do:** Find an answer that, combined with the premises, makes the conclusion 100% certain.
**Key:** SA answers often over-deliver. They're stronger than NAs.

---

### 4. Strengthen
**What it asks:** Which answer makes the argument *more convincing*?
**What to do:** Identify the gap. Pick the answer that best supports the link between premises and conclusion.
**Key:** The answer doesn't have to *prove* the conclusion — just make it more likely.

---

### 5. Weaken
**What it asks:** Which answer *undermines* the argument?
**What to do:** Find the gap. Pick the answer that attacks it — makes the conclusion less likely given the premises.
**Key:** The answer doesn't have to *disprove* the conclusion — just damage the reasoning.

---

### 6. Main Point / Main Conclusion
**What it asks:** What is the overall conclusion of the argument?
**What to do:** Apply the "therefore test." The correct answer restates the conclusion — no more, no less.
**Common traps:** Premises dressed up to look like conclusions; overly broad or narrow paraphrases.

---

### 7. Inference / Must Be True
**What it asks:** What must be true based *only* on the stimulus?
**What to do:** Do NOT bring in outside knowledge. The answer must follow directly from the text.
**Key:** "Must be true" is stronger than "could be true." Eliminate anything that's merely possible.

---

### 8. Paradox / Explain the Discrepancy
**What it asks:** Which answer explains why two seemingly contradictory facts can both be true?
**What to do:** Identify the two conflicting facts. Find an answer that reconciles them.
**Common traps:** Answers that explain only one side, or that make the paradox *worse*.

---

### 9. Parallel Reasoning
**What it asks:** Which answer has the same logical structure as the stimulus?
**What to do:** Abstract the argument to its form (e.g., "All A are B; X is A; therefore X is B"). Match the structure, not the topic.

---

### 10. Point at Issue / Disagree
**What it asks:** What do the two speakers *disagree* about?
**What to do:** The correct answer must be something one speaker would say YES to and the other NO.
**Key:** Both speakers must have a clear, expressed view on the correct answer.

## Quick Reference Table

| Question Type | Core Task | Key Technique |
|--------------|-----------|---------------|
| Flaw | Name the reasoning error | Match to flaw types |
| Necessary Assumption | Find the minimum gap-filler | Negation Test |
| Sufficient Assumption | Find the guarantee | Formal logic often helpful |
| Strengthen | Support the gap | Ask "does this help?" |
| Weaken | Attack the gap | Ask "does this hurt?" |
| Main Point | Identify the conclusion | Therefore Test |
| Inference/MBT | Derive from stimulus only | No outside knowledge |
| Paradox | Reconcile two facts | Explain both sides |
| Parallel Reasoning | Match logical structure | Abstract to form |
| Point at Issue | Find the real disagreement | Both speakers must have a view |
