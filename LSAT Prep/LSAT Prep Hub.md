## 📚 Study Plan

### Phase 1 — Foundation (Weeks 1–4)

**Goal:** Learn the test structure, core question types, and fundamental reasoning skills.

**Logical Reasoning**
- [ ] Learn the 5 core question types: Flaw, Necessary Assumption, Sufficient Assumption, Strengthen, Weaken
- [ ] Practice identifying Conclusions and Premises in every stimulus
- [ ] Master conditional logic (If/Then, contrapositive, negation)
- [ ] Learn to spot common argument flaws (correlation ≠ causation, sampling errors, etc.)

**Reading Comprehension**
- [ ] Learn passage structure: Main Point, Author Perspective, Paragraph roles
- [ ] Practice active reading — summarize each paragraph in one sentence
- [ ] Learn the RC question types: Main Point, Author's Attitude, Inference, Detail, Analogy
- [ ] Do 1 full RC passage (4 questions) per study session

**Weekly Target:** 5 sessions/week, ~90 min each

---

### Phase 2 — Skill Building (Weeks 5–10)

**Goal:** Increase accuracy and start timed practice.

- [ ] Begin timed section practice (35 min per section)
- [ ] Complete 2 full practice tests
- [ ] Blind review every missed question — understand *why* before checking explanations
- [ ] Build an error log (see below)
- [ ] Focus extra time on weakest question types identified from error log

**Weekly Target:** 5–6 sessions/week, ~2 hours each

---

### Phase 3 — Test Simulation (Weeks 11–16)

**Goal:** Simulate test conditions, refine timing, peak performance.

- [ ] Take 1 full practice test per week under real conditions
- [ ] Strict 35-min section timing, no breaks between sections
- [ ] Review every test within 24 hours using blind review method
- [ ] Adjust strategy based on persistent error patterns
- [ ] Final week: light review only, rest before exam

## 🧠 Key Concepts & Notes

### Logical Reasoning

#### Argument Structure
- **Conclusion:** What the author is trying to prove
- **Premises:** Evidence given to support the conclusion
- **Assumption:** Unstated premise the argument depends on

#### Common Flaws
- Correlation → Causation
- Unrepresentative sample
- Equivocation (term shift)
- Appeal to authority
- Circular reasoning
- Absence of evidence treated as evidence of absence

#### Conditional Logic
- "If A → B" means: whenever A is true, B must be true
- **Contrapositive:** ~B → ~A (always valid)
- **Mistaken Reversal:** B → A (invalid)
- **Mistaken Negation:** ~A → ~B (invalid)

---

### Reading Comprehension

#### Passage Types
1. Law/Policy
2. Science/Natural world
3. Humanities/Arts
4. Social Science

#### Active Reading Method
1. Read intro sentences carefully — they signal the topic and direction
2. Note each paragraph's *purpose* (not just content)
3. Track: Main Point | Author's View | Tone (neutral/critical/supportive)
4. Don't memorize details — know *where* they are
