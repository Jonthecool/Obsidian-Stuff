# LR — Argument Structure

> Every Logical Reasoning stimulus is built from the same skeleton. Master this before anything else.
> Back to [[LSAT Prep Hub]]

---

## The Three Parts of an Argument

### Conclusion
- What the author is **trying to prove**
- The point the entire argument builds toward
- Often (not always) signaled by: *therefore, thus, so, hence, consequently, clearly, it follows that*

### Premises
- **Evidence** offered to support the conclusion
- Facts, data, observations the author treats as given
- Often signaled by: *because, since, given that, for, as indicated by*

### Assumption
- An **unstated premise** the argument secretly depends on
- The gap between what the premises say and what the conclusion claims
- If the assumption is false, the argument collapses
- Never stated — you must infer it

---

## How to Break Down Any Stimulus

1. **Find the conclusion first** — ask "What is the author trying to convince me of?"
2. **Find the premises** — ask "What reasons does the author give?"
3. **Identify the gap** — ask "What must be true for the premises to actually support the conclusion?"

## Common Conclusion Indicators
| Word/Phrase | Example |
|-------------|---------|
| Therefore | "...therefore, the policy is flawed." |
| Thus | "...thus, we can conclude..." |
| So | "...so prices will rise." |
| Hence | "...hence, the treatment works." |
| Clearly | "Clearly, more funding is needed." |
| It follows that | "It follows that crime will decrease." |
| This shows that | "This shows that the hypothesis is wrong." |

---

## Common Premise Indicators
| Word/Phrase | Example |
|-------------|---------|
| Because | "...because the data shows..." |
| Since | "Since all mammals breathe air..." |
| Given that | "Given that costs have risen..." |
| For | "...for the study was flawed." |
| After all | "After all, the evidence suggests..." |

---

## Watch Out: Conclusions Without Indicators

Many LSAT conclusions have **no indicator word**. The conclusion is just stated matter-of-factly somewhere in the stimulus — often at the beginning or end.

*Strategy:* Try the "therefore test" — can you insert "therefore" before a sentence and have the rest of the argument support it? If yes, that's the conclusion.
